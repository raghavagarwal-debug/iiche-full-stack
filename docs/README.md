# 📖 About

The **IIChE Student Chapter, BIT Mesra** is a premier student organization dedicated to promoting innovation, technical excellence, and professional growth in Chemical Engineering. This website serves as the official digital platform of the chapter, showcasing departmental initiatives, technical events, Coalescence, workshops, alumni interactions, executive boards, achievements, and chapter activities.

Designed with a modern and responsive interface, the platform provides an engaging experience across desktops, tablets, and mobile devices while reflecting the vision and identity of the IIChE Student Chapter.
